libpcp

Port Control Protocol (RFC 6887) client. Ask a router or firewall to open a port, with retransmissions, lease renewals and server-restart detection built in.

C23MITRFC 6887

You drive the loop

Hand the library datagrams and the current time. It tells you what to send and how long you can sleep.

  • Works with any event loop or socket API
  • No allocations after a mapping is created
  • Tests run hours of retransmissions without waiting

Inspired by the sans-I/O approach to writing network protocol libraries.

while (running) {
  pcp_event_t event;
  do {
    event = pcp_session_poll(session, now_ms());
    switch (event.type) {
    case PCP_EVENT_SEND:
      send(socket, event.send.data, event.send.size, 0);
      break;
    case PCP_EVENT_MAPPED:
      // reachable at event.mapped.external
      break;
    default:
      break;
    }
  } while (event.type != PCP_EVENT_TIMEOUT);

  // wait for a datagram or event.timeout.deadline
}
